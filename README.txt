MEETA BIRTHDAY WEBSITE
=======================

Files:
- index.html
- assets/meeta-profile.jpg
- assets/mirror-birthday.jpg
- assets/birthday-collage.jpg

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Publish on GitHub Pages:
1. Create a GitHub repository (or use your existing HBD repository).
2. Upload index.html and the entire assets folder to the repository root.
3. In Settings > Pages, select Deploy from a branch, choose main and /(root).
4. Save and wait for GitHub Pages to publish.

The page is responsive and uses no backend. Google Fonts require internet access;
the rest of the page and photos are local files. All personal message copy is
embedded in index.html and can be edited directly.
